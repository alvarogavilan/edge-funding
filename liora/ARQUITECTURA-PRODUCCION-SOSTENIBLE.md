## Reglas innegociables
0 euros autorizados. Nunca activar servicios, pruebas renovables, claves ni GPU con coste. GitHub Pages aloja interfaz pública, NO un motor GPU ni un servidor de secretos. iPhone como único equipo necesario para el usuario. No GitHub Actions propios. No tocar Card Vault. Commits [skip ci].

## Módulos
1. Identidad: LIORA-IDENTIDAD-001, imagen original auténtica, huella SHA-256 y versiones de referencia. Fijar en UI no equivale a garantizar consistencia en vídeo.
2. Investigación: evidencias verificables de tendencias con fecha, datos reales y criterios originales; nunca inventar métricas.
3. Proyectos: personaje propio, escenas con estado previo, brocha, mano, producto y evolución de maquillaje.
4. Adaptador de generadores: proveedor intercambiable, modelo/versión, requisitos, licencia comercial, capacidad de imagen de referencia, precio real, estado de trabajo, errores y salida reproducible. Si no hay motor, marcar BLOQUEADO sin simular vídeo.
5. Música: letras, melodías y pistas propias; contratos o permisos si intervienen terceros; documentación de autoría y prueba de voz cantada y sincronizada.
6. Control de calidad: revisión por versión de archivo, rostro, manos, brochas, movimiento, contacto piel-producto, coherencia del maquillaje, labios, audio y originalidad.
7. Entrega: máster vertical 1080x1920 sin marca de agua, MP4 H.264/AAC, textos para Instagram y TikTok, control de publicación humana.
8. Archivo y recuperación: proyectos y medios persistentes, copias de seguridad verificadas y segregación por marca. No confiar solo en almacenamiento local de Safari.
9. Métricas: fuente, fecha, visualizaciones, guardados, retención cuando esté disponible, seguidores adquiridos; no inferir números.

## Seguridad y coste
No colocar API keys, secretos ni activos privados en JS público o repositorio público. Un motor de GPU remoto necesita entorno de ejecución adicional, gratuito y verificablemente disponible; su existencia no está garantizada. Evaluar condiciones comerciales de cada modelo. Si el coste calculado excede 0 EUR, no generar.

## Aceptación estricta por hitos
P0: clip real de 3–5 s con rostro oficial, brocha tocando piel, archivo MP4 que se vea en Safari, prueba reproducible y coste 0.
P1: segunda escena que conserve la identidad y el maquillaje previamente aplicado.
P2: canto original con sincronización labial real.
P3: Reel completo 25–30 s aprobado, exportado para ambas plataformas.

P6: habilitar otro canal distinto solo cuando lo anterior funcione.
