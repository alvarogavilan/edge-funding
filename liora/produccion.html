Liora Studio

Producción audiovisual de una única protagonista virtual. Los datos viven en este iPhone; la URL es pública, la app no es privada por sí misma.

Identidad oficial de Liora

La fotografía oficial es la referencia maestra. Todas las escenas se comparan contra ella con reconocimiento facial que se ejecuta en este iPhone (las imágenes no salen del dispositivo salvo cuando tú lances una generación).

Añadir referencia

Las referencias de ángulo se aceptan solo si el sistema reconoce a la misma mujer de la fotografía oficial (distancia ≤ 0,55). Si no, se marcan como rechazadas y no se usan.

Rasgos invariables (texto para los prompts)

Comparar una imagen con Liora

Copia de seguridad de la identidad

Las referencias se guardan en Safari y persisten entre proyectos. Si borras los datos de Safari se pierden: guarda una copia en Archivos/iCloud.

Proyecto

Escenas (8 etapas obligatorias)

PENDIENTE → GENERANDO → REVISIÓN → APROBADO / RECHAZADO → EXPORTADO. Cada etapa parte del último fotograma aprobado de la anterior.

Canción del proyecto

Solo canciones originales o con licencia válida para Instagram y TikTok. La pista se recorta por etapas para generar el canto y sincronizar labios.

Voz oficial de Liora

La voz debe ser la misma en todos los vídeos. Guarda aquí cómo se produce y una muestra de referencia para comparar a oído cada canción nueva.

La sincronía labial de voz hablada no garantiza canto: vocales sostenidas, respiraciones y notas largas fallan con frecuencia. Cada clip se revisa con el indicador boca↔voz y a ojo.

Máster del vídeo completo

El montaje se renderiza en tiempo real en el iPhone: mantén la pantalla encendida y Safari en primer plano.

Despliegue del backend

  1. Cloudflare → Workers & Pages → Create → «Hello World» → nombre liora-backend.
  2. Edit code → pega el código (botón de abajo) → Deploy.
  3. Settings → Variables: secretos FAL_KEY y LIORA_ACCESS_KEY; variables ALLOW_PAID=false, MAX_USD_PER_JOB=3, MAX_USD_TOTAL=25, ALLOWED_ORIGIN=https://alvarogavilan.github.io.
  4. Storage → KV → crear «liora» y vincularlo como LIORA_KV.
  5. Para autorizar gasto: cambiar ALLOW_PAID a true.
